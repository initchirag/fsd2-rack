# Social Media Post Planner

Name: HARKARAN SINGH  
UID: 24BCY70083  
Section: 24BCY-1(A)

This project is a React + Vite web application designed to help users organize and manage social media posts in a simple, interactive calendar view. It provides a visual way to plan content for different platforms such as Twitter, Instagram, LinkedIn, and YouTube, while keeping track of each post's date, time, and status.

## Project Overview

The application acts as a lightweight content planner for marketers, creators, or students learning frontend development. Users can:

- View posts arranged by date on a monthly calendar
- Add, update, and delete posts
- Drag and drop posts to change their scheduled date
- See platform-specific colors and status indicators
- Track content progress through Draft, Scheduled, and Published states

## Key Features

- Interactive calendar interface
- Responsive and clean UI
- Reducer-based state management for predictable updates
- Memoized components to improve rendering efficiency
- Built-in in-browser test runner to validate core logic

## Technologies Used

- React
- Vite
- JavaScript
- CSS
- ESLint

## How to Run

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the local URL shown in the terminal to view the app.

## Project Purpose

This project demonstrates how a modern React application can be used to build a practical planning tool while also showcasing important React concepts such as state management, component optimization, and basic testing.
